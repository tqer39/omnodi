# 開発言語の選定

## 要件

独自 DSL と Terraform から対話型の構成図を生成し、CDN や開発サーバーなしで操作できる単一 HTML として配布する。
ブラウザー上のビューアー、属性エディター、CLI、ライブラリで同じモデルと描画基盤を共有する。
macOS、Linux、Windows で同じ手順で開発・検証できる。

## 候補

TypeScript（Node.js と npm）、Go、Python を比較した。
Go と Python は CLI に向くが、ブラウザーの描画とエディターを別言語で実装する必要があり、
共通モデルを二重に保守することになる。

## 選定理由

TypeScript を採用する。ブラウザーのビューアー、CLI、ライブラリを１つの言語と型定義で実装でき、
React Flow や ELK などの描画ライブラリをそのまま利用できるため。
実行環境は mise で固定した Node.js、依存は package-lock.json で固定した npm を使う。
アイコン更新の補助スクリプトだけは外部パッケージを使わない Python で実装する。
