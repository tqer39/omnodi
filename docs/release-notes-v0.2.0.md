# Omnodi v0.2.0

Infra Canvas から Omnodi へ改名してから初めてのリリースです。
Docker イメージの配布先は `ghcr.io/tqer39/omnodi` になります。

## 主な変更

- インフラ構成図に加え、UML・業務フロー・因果ループの図とサンプルに対応しました。
- AWS リソースのサジェストと連続追加、矢印の形・アイコン表示の切り替えを追加しました。
- ルーペによる局所拡大と起動中の縮尺固定に対応し、画面外でボタンを離した後もパンが続く問題を修正しました。
- 脆弱性の公開情報と攻撃経路を構成図で確認できるようにしました。
- サンプルと上部メニューを復元し、依存関係を更新しました。
- 新しい GHCR パッケージの初回配布を妨げていた匿名認証による事前照合を修正しました。配布後の匿名取得・両 CPU 検証は引き続き必須です。

## 移行

CLI・パッケージ・コンテナーの名称は `omnodi` です。既存 DSL の移行は不要です。
旧設定ディレクトリー、保存済み API キー、CVE キャッシュ、旧 HTML の読み込み互換性を維持しています。
旧イメージ `ghcr.io/tqer39/infra-canvas` の v0.1.0・v0.1.1 は変更しません。
今後の更新では `ghcr.io/tqer39/omnodi` を使用してください。

Docker 版の CLI 用 PNG/PDF 出力に必要な Chromium は引き続き同梱しません。
ブラウザーからの PNG 出力・印刷、または開発環境を使用してください。
